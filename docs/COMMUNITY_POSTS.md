# Ready-to-Use Community Post Templates

Use these copy-paste templates when sharing your project online on Steam, Reddit, or Discord.

---

## 1. Reddit Post Template (r/GearCity & r/tycoon)

**Title**: *I made an open-source Engine Optimizer & XML Blueprint Tool for GearCity (with Web App!)*

**Body**:
```markdown
Hey everyone!

I built an open-source tool and web application for **GearCity** to help optimize engine designs and calculate vehicle demographics.

### 🌟 What it does:
1. **Engine Optimizer**: Finds the best Layout, Cylinders, Fuel type, Induction, Valvetrain, Bore/Stroke, and Sliders to maximize Horsepower or Torque within your budget ($), weight (kg), and engine bay size limits.
2. **Direct XML Blueprint Download**: Generates `.xml` engine blueprints that you can drop straight into your `Designs/Engines` folder—no need to manually adjust 15 sliders in-game!
3. **Vehicle Demographic Targeter**: Shows the optimal buyer demographics (Gender and Age brackets) for all 30 vehicle body types.
4. **Chassis & Gearbox Recommendations**: Unlock timeline suggestions for frames, suspensions, and transmissions.

### 🌐 Try the Web App:
https://poompoowit.github.io/GearCity/

### 🔗 GitHub Repository (CLI & Python Source):
https://github.com/poompoowit/GearCity

### 📚 Source & Formulas:
All calculations and engineering models are estimated based on the formulas provided on the official [GearCity Wiki](https://wiki.gearcity.info/).

Feedback and suggestions are very welcome! Hope this helps fellow players in their playthroughs.
```

## 2. Steam Community Guide Template

**Title**: *Engine Optimizer, Demographic Targeter & Blueprint Generator Tool*

**Description**: *A free web tool and Python package to solve for optimal engine designs for any game year and export XML blueprints directly.*

**Content Sections**:
1. **Web App Link**: `https://poompoowit.github.io/GearCity/` (No install needed).
2. **Introduction**: Overview of the optimizer and demographic targeter.
3. **In-Game XML Import Guide**:
   - Save path on Windows: `Documents\My Games\GearCity\Designs\Engines\`
   - Save path on Linux / Steam Deck: `~/.local/share/GearCity/Designs/Engines/`
   - Save path on macOS: `~/Library/Application Support/GearCity/Designs/Engines/`
4. **Demographics Reference Table**: Best buyer age & gender for each body style.
