📖 How to Import XML Blueprints In-Game

1

Design & Download Blueprint

Use the Engine Optimizer tab to find your optimal engine, then click "Download Blueprint (.xml)".

2

Place the XML file in your GearCity Designs folder

Copy the downloaded XML file to the path for your OS:

🪟 Windows: Documents\My Games\GearCity\Designs\Engines\
🎮 Steam Deck / Linux: ~/.local/share/GearCity/Designs/Engines/
🍏 macOS: ~/Library/Application Support/GearCity/Designs/Engines/
3

Load Directly In-Game!

Launch GearCity $\rightarrow$ open the Engine Designer $\rightarrow$ click Load Blueprint. Your engineered engine is ready to build immediately with all sliders set perfectly!
